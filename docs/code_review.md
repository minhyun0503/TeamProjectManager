# 이번 코드 점검 결과

| 확인한 문제 | 수정한 동작 | 확인 방법 |
|---|---|---|
| 달력이 별도 일정만 조회해 업무 마감일이 보이지 않음 | 업무 원본을 읽어 마감일에 표시. 상태·담당자 함께 표시 | 월초·월말·윤년 2/29·팀 구분·같은 날 여러 업무·완료·수정·삭제 등 13개 검사 |
| 자동 조회를 시작한 뒤 사용자가 다른 항목을 골라도 예전 선택으로 되돌아갈 수 있음 | 조회가 끝난 순간의 사용자 선택 유지 | 조회를 의도적으로 지연시킨 뒤 메모·아이디어 선택 변경 검사 |
| 팀에서 나간 담당자의 업무를 수정할 때 다른 사람이 기본 선택될 수 있음 | 선택을 비워 사용자가 새 담당자를 직접 지정 | 실제 수정창을 열어 선택 상태 검사 |

기존 기능 52개 검사와 새 달력 13개 검사가 실제 Java 17에서 통과했습니다. 9개 탭 및 메모·아이디어 자동 갱신도 확인했습니다. 전체 프로젝트의 `.project`는 하나입니다.

화면을 옮길 때 업무 정보를 다시 읽으므로, 업무 마감일을 바꾸면 달력을 다시 열거나 새로고침해 확인합니다. 원본 업무를 일정 표에 복사하지 않습니다.

이 검사는 모든 환경에서 오류가 전혀 없다는 보장은 아닙니다. 실제 MySQL 서버·여러 물리 PC의 연결은 이번 환경에서 확인하지 못했습니다. 현재는 수업 시연용 계정·로그인 방식을 사용하며 운영 서비스의 인증 체계를 검증한 작업은 아닙니다.
