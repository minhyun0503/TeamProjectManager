## 설명할 수 있는지 확인하는 방법

1. 화면에서 버튼 하나를 골라 실제로 눌러 봅니다.
2. Eclipse에서 그 버튼의 addActionListener를 찾습니다.
3. 연결된 메서드가 어떤 값을 읽는지 적습니다.
4. DAO의 SQL에서 어느 표의 어느 행이 바뀌는지 설명합니다.
5. 성공·실패 뒤 화면이 어떻게 되는지 말합니다.

예를 들어 “메모는 version으로 낙관적 잠금을 구현했다”는 문장만 외우는 것보다, **A와 B가 버전1을 읽고 A가 먼저 저장하면 B가 왜 저장하지 못하는지**를 설명할 수 있어야 합니다.

## 서로에게 한 번씩 물어보기

| 담당 | 연습 질문 |
|---|---|
| 공통 | 회원 번호10과 팀 번호7은 왜 서로 다른가? |
| 로그인·메모 | 두 사람이 같은 메모를 고치면 UPDATE 결과0은 무슨 뜻인가? |
| 업무 | 보드에서 완료로 바꾼 결과가 표에도 보이는 이유는? |
| 일정 | 10월30일~11월2일 일정이11월에도 보이려면 어떤 조건이 필요한가? |
| 자료·협업 | 공감 수만 저장하지 않고 누가 눌렀는지도 저장하는 이유는? |

각 담당 설명의 끝에 답을 확인할 수 있는 내용이 있습니다. 마지막에는 코드 색인으로 실제 메서드 위치를 열어 가리키면서 설명해 보세요.
