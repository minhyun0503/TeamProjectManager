# Eclipse IDE 2023-12에서 가져오기

이 프로젝트는 **Eclipse 2023-12 + Java 17**을 기준으로 설정했습니다. Java 21 JDK도 사용할 수 있지만 소스와 출력 바이트코드는 17 수준으로 맞춥니다. IDE 버전과 설치된 JDK 버전은 서로 다른 정보입니다.

## 1. JDK 확인

Windows 터미널에서 `java -version`, `javac -version`을 실행합니다. Eclipse에 포함된 실행용 Java와 프로젝트 컴파일에 사용할 JDK가 다를 수 있습니다. javac를 찾을 수 없다면 JDK 설치 경로의 bin이 PATH에 등록됐는지 확인하세요.

## 2. 프로젝트 가져오기

1. ZIP 전체를 압축 해제합니다. src·lib·docs·.project·.classpath가 같은 폴더에 있어야 합니다.
2. Eclipse에서 `File → Import → General → Existing Projects into Workspace`를 선택합니다.
3. `Select root directory`에 압축을 푼 폴더를 지정합니다.
4. `TeamProjectManagerFeedback`을 선택하고 Finish를 누릅니다.
5. `src/teamproject/common/Main.java`를 우클릭하여 `Run As → Java Application`을 실행합니다.

Java 파일을 하나씩 기존 프로젝트에 복사하면 클래스패스·JDBC JAR·스키마 리소스가 빠질 수 있으므로 프로젝트 단위로 가져오세요. 현재 브랜치의 TeamProjectManagerFeedback 프로젝트를 실행합니다.

## 3. JRE System Library 오류가 보이면

`Window → Preferences → Java → Installed JREs`에서 설치된 JDK 17 경로를 Add합니다. JDK 21만 설치돼 있다면 그 경로를 등록하고, `Execution Environments → JavaSE-17`에서 호환 JDK를 연결할 수도 있습니다.

프로젝트 우클릭 → `Properties → Java Build Path → Libraries`에서 `JRE System Library [JavaSE-17]`을 확인합니다. 연결이 풀렸다면 해당 항목을 Edit하여 `Execution environment: JavaSE-17`을 선택합니다.

프로젝트 우클릭 → `Properties → Java Compiler`의 compliance level은 17입니다. 제공한 `.settings/org.eclipse.jdt.core.prefs`가 프로젝트별 설정을 저장합니다. IDE 자체를 Java25로 올리거나 최신 Eclipse로 바꿀 필요는 없습니다.

## 4. 한글·스키마·드라이버

- `Properties → Resource → Text file encoding`은 UTF-8입니다.
- lib 폴더의 MySQL·H2 JAR 두 개가 Build Path에 포함되어 있어야 합니다.
- `Project → Clean` 후 자동 빌드합니다.
- `bin/teamproject/common/schema.sql`이 생기는지 확인합니다. src 안의 비Java 리소스이므로 기본 Eclipse 빌더가 복사합니다.
- 스키마 리소스가 빠지면 build.bat 또는 build.sh를 실행해서 복사할 수 있습니다.

`module-info.java`의 모듈 이름은 TeamProjectManagerFeedback이며 JDK 표준 java.sql·java.desktop을 사용합니다. 패키지 이름을 새로 바꾸거나 module-info를 지울 필요는 없습니다.

## 5. 명령행 실행

build·test 스크립트는 `javac --release 17`을 사용합니다. 설치된 컴파일러가 21이어도 Java17 바이트코드를 만듭니다. Java17보다 낮은 컴파일러에서는 실행하지 마세요. 데모 계정은 demo1~demo5 / demo1234입니다.

근거: [Eclipse 4.30 릴리스 노트](https://eclipse.dev/eclipse/development/readme_eclipse_4.30.html)는 Java SE17 환경을 기준으로 설명하고, [2023-12 JDT 문서](https://eclipse.dev/eclipse/news/4.30/jdt.html)는 해당 릴리스의 언어 지원을 안내합니다. 이번 수정은 프로젝트 버전 설정·리소스 인코딩·실행 스크립트를 맞춘 것이며, 수업 기능과 팀원 역할은 동일합니다.
